# Welcome to davidburke.me 👋

This is the source code for my personal website and blog—a dedicated space for exploring the intersection of **digital accessibility**, **inclusive design**, and the fascinating history of the technologies we use every day.

### The Purpose
I built this site to document and share insights on how designing for the "edges" often leads to better experiences for everyone. From the origins of dark mode and autocomplete to deep dives into modern OS accessibility tools, the goal is to highlight the "Curb-Cut Effect" in our digital lives.

### Built With
- **[Hugo](https://gohugo.io/):** The fast and flexible static site generator.
- **[Stack Theme](https://github.com/CaiJimmy/hugo-theme-stack):** A modern, card-based design by Jimmy Cai.
- **Custom Touches:** Notion-style tag coloring, custom-themed SVG featured images, and enhanced accessibility features.
